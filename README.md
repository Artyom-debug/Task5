# Task5 — генератор каталога фильмов

Учебное ASP.NET Core-приложение с веб-интерфейсом. Поддерживает русский и английский языки, пагинацию, просмотр таблицей или галереей, выбор seed и средних значений лайков и отзывов.

## Как работает

1. По выбранным seed и локали `GET /api/movies` вычисляет для каждого фильма `movieSeed` из пользовательского seed, локали и порядкового индекса.
2. По `movieSeed` Bogus генерирует год, актёров и режиссёра, а название собирается из локальных JSON-словарей.
3. При открытии фильма `POST /api/movies/movie` параллельно собирает описание и 10 отзывов из частей локальных JSON-ресурсов и создаёт 10-секундный трейлер через FFmpeg. Видеофрагменты выбираются по `movieSeed`, музыка — по жанру; на видео добавляются анимированные титры.
4. Количество лайков и показываемых отзывов определяется по `movieSeed` и выбранным средним значениям. Интерфейс показывает нужное число отзывов из десяти сгенерированных.
5. Текст и байты трейлера хранятся в памяти до 4 часов. Видео отдаётся через `GET /api/movies/{movieSeed}/trailer`; после перезапуска приложения кэш создаётся заново.

Постоянная база данных и внешний AI-сервис не используются.
